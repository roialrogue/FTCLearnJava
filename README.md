# FTCLearnJava

Java fundamentals examples — data types, operators, and basic program structure — built to be taught in a classroom setting: the examples get displayed and walked through, then tweaked hands-on.

## What's inside

- `Java/DataTypes.java` — declaring and initializing variables across Java's primitive types
- `Java/Operators.java` — arithmetic operators and expressions
- `Java/Example.java`, `Java/ExampleNotes.java` — a minimal Java program, annotated line by line
- `Java/NewFun.java` — empty scratch file

## How to use it

Meant to be taught, not just read: walk through each example in `Java/` as a class, then have people modify and rerun them to see what changes.
